# Git

This repo is **GDI only**. Product work goes through a pull request, not straight to `main`.

English only: commits, PR titles, comments, docs, and UI.

1. Branch from `main`: `feat/…`, `fix/…`, or `chore/…`
2. Commit on that branch
3. Push the branch
4. Open a PR into `main` (title + description)
5. Merge the PR on GitHub

A new indicator is a new repository, not a branch here.
